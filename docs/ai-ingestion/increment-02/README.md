# FinGence 2.0 Increment 02

Implemented locally on 20 October 2026. **RECORDED_TEST; live inference NOT EXECUTED.**
Synthetic documents only. No API key setup, paid inference, commit, publication or deployment.

This increment adds semantic field policies, complete source dispositions, independently
verified blueprint rebinding, and a separate local developer evaluation page. Real file
extraction and deterministic financial validation execute. Interpretation settings are
hand-authored test inputs; they are not generated by an LLM. Model accuracy is unmeasured.

## Run locally

Use the existing Increment 01 environment: Node 24.x, pnpm 11.19.0, Python 3.12,
and the packages in the unchanged `requirements-ai-lock.txt`:

```bash
pnpm install --frozen-lockfile
python3.12 -m venv .venv-ai
.venv-ai/bin/python -m pip install -r requirements-ai-lock.txt
.venv-ai/bin/python -m pip check
node scripts/ai-demo-02.mjs
```

Open `http://127.0.0.1:3105/ai-ingestion/developer`.
The launcher binds loopback, enables the explicit local replay flags and disables live
inference. Model weights and Python packages require downloads during first setup;
they are not in the review ZIP. Extraction reuses the already benchmarked local
Docling/RapidOCR installation. No new dependency was added.

The ordinary finance page remains at `/ai-ingestion`. It retains Increment 01's simple
upload/process/evidence interaction and honestly blocks unavailable live inference.
It has no replay selector and does not import the 0.2 replay path. This deliberate
separation preserves every Increment 01 file byte-for-byte. The new 0.2 schema is not
yet connected to the finance-facing live provider. Do not present the developer page
as a completed finance-user AI workflow.

## Reproduce the experiment

```bash
node --conditions=react-server scripts/ai-increment-02.mjs evaluate
node --conditions=react-server scripts/ai-increment-02.mjs replay bank-narrative.csv
node --conditions=react-server scripts/ai-increment-02.mjs replay ledger-dmy.xlsx swap
node --conditions=react-server scripts/ai-increment-02.mjs replay precision.csv reuse
pnpm test tests/ai-ingestion-02
```

Evaluation writes the public metric summary to `evidence/evaluation.json` and full
synthetic traces to ignored `.ai-local/increment-02/`. The runtime does not read the
evaluation-only labels in `tests/fixtures/ai-ingestion-02/`. No command above loads an
environment credential file, invokes a model or requests API spending. The CLI explicitly
sets live approval to zero. No automatic inference retry is introduced.
